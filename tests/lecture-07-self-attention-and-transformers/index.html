Part 1 · Multiple Choice — Core Concepts

Choose one answer for each question.

Q1Multiple Choice7 · slides 14–19
Why can a contextual embedding represent “it” differently in “The chicken did not cross the road because it was too tired” and “…because it was too wide”?

Answer: C. It incorporates information from the surrounding tokens.

A contextual representation depends on the surrounding tokens. The continuation can help connect “it” to the chicken or the road. A static word embedding uses the same lookup vector for “it” in both sentences.

Q2Multiple Choice7 · slides 22–28
Which description correctly matches the roles of queries, keys and values in an attention head?

Answer: B. Queries are compared with keys to obtain weights; those weights combine the values.

A query describes what the current position seeks. Its similarity to each key determines an attention score. After normalization, these weights form a weighted sum of value vectors.

Q3Multiple Choice7 · slides 29–31
What makes an attention layer a self-attention layer?

Answer: A. Queries, keys and values are derived from the same input sequence.

“Self” refers to the common source sequence. The learned query, key and value projections are usually different, and a token can attend to other positions as well as itself, subject to any mask.

Q4Multiple Choice7 · slides 32, 36
Why does scaled dot-product attention divide each query–key dot product by √dk?

Answer: D. To control score magnitude as the key/query dimension grows and reduce softmax saturation.

Under the usual independent, zero-mean, unit-variance component assumption, a dot product has variance dk. Dividing by √dk brings its variance back to about 1. Very large score differences can otherwise produce saturated softmax distributions and small gradients.

Q5Multiple Choice7 · slides 32, 36, 70
In softmax(QKT/√dk)V, rows correspond to queries and columns to keys. Along which dimension is softmax applied?

Answer: C. Across keys, separately for each query.

Each query needs its own distribution over the available key positions. Softmax therefore normalizes each row over keys. Assuming at least one unmasked key, each row sums to 1.

Q6Multiple Choice7 · slides 28, 33
After an attention head computes its normalized weights, which vectors are directly combined to produce its output?

Answer: A. Value vectors.

The head output is a weighted sum of values. Queries and keys determine how much each value contributes; they are not the vectors being averaged in this step.

Q7Multiple Choice7 · slides 38–40
How are the outputs of multiple attention heads combined in the original Transformer?

Answer: B. Concatenate the head outputs, then apply a learned output projection.

Each head has its own learned projections and can capture different relations. Their output vectors are concatenated and multiplied by an output projection WO to return to the model dimension.

Q8Multiple Choice7 · slides 42–43
Why is positional information added to token embeddings in the standard Transformer encoder?

Answer: D. To supply order information that unrestricted self-attention does not encode by itself.

Without positional information or another position-dependent mechanism, unrestricted self-attention treats a permutation of input tokens as the corresponding permutation of outputs. Position encodings let the model use where tokens occur, as well as what they are.

Q9Multiple Choice7 · slide 44
What does the position-wise feedforward network do within one Transformer layer?

Answer: C. It applies the same nonlinear transformation independently to each position.

Within a layer, the same FFN parameters are shared across positions. The FFN transforms features at each position; attention is the sub-layer that mixes information across positions. The FFN adds nonlinear feature processing.

Q10Multiple Choice7 · slide 46
Which two main sub-layers form one encoder layer in the original Transformer?

Answer: A. Multi-head self-attention and a position-wise feedforward network.

An encoder layer contains multi-head self-attention followed by a position-wise FFN, with residual connections and layer normalization around the sub-layers. Encoder–decoder cross-attention belongs to the decoder.

Q11Multiple Choice7 · slides 49, 53
In encoder–decoder cross-attention for translation, where do queries, keys and values come from?

Answer: B. Queries come from decoder states; keys and values come from encoder outputs.

The decoder query asks which source information is useful for its current target position. The encoder provides the source-side keys and values. Source and target sequence lengths do not have to match.

Q12Multiple Choice7 · slides 50–51
A student implements causal masking by setting future-token logits to 0 before softmax. What is the problem?

Answer: D. A zero logit still contributes exp(0) = 1, so future tokens can receive positive attention weight.

An additive causal mask uses −∞ at forbidden positions (or an appropriate large negative value in an implementation). Their exponentials then become zero. Merely replacing a score with 0 does not exclude that position.

Q13Multiple Choice7 · slides 47–48
Ignoring dropout, which expression matches the post-normalization “Add & Norm” block shown in the lecture?

Answer: C. LayerNorm(x + Sublayer(x))

The residual connection first adds the sub-layer input to its output; layer normalization is then applied to that sum. This question refers to the original post-norm block in the slides, not the pre-norm variants used in other Transformers.

Q14Multiple Choice7 · slides 50–51, 57
How can a Transformer decoder compute training predictions at all target positions in parallel without leaking the target token being predicted?

Answer: A. Use right-shifted gold target inputs together with causal self-attention masking.

With teacher forcing, the gold target sequence is available during training. Shifting it right puts only earlier target tokens at or before each prediction position, while the causal mask blocks later positions. Predictions across these positions can then be computed in parallel.

Q15Multiple Choice7 · slides 70–73
What is the main idea behind dense FlashAttention as introduced in the lecture?

Answer: D. Compute attention in blocks and reduce transfers between HBM and on-chip SRAM.

FlashAttention reorganizes exact attention using tiling and recomputation to reduce memory reads and writes, avoiding storage of the full attention matrix in HBM. Dense FlashAttention does not gain its speed by dropping token pairs.

Q16Multiple Choice7 · slide 75
In the Vision Transformer (ViT) shown in the lecture, what plays the role of the input token sequence?

Answer: B. Embeddings of image patches, with positional information.

ViT splits an image into patches, projects flattened patches into embeddings, and supplies positional information. A Transformer encoder can then process this sequence of patch representations.

Part 2 · Multiple Choice — Calculations & Applications

Choose one answer. Numerical examples are new exercises based on the lecture methods.

Q17Multiple Choice7 · slides 32–34
For one query, the two scaled attention scores are [0, ln 3]. The value vectors are v1 = [4, 0] and v2 = [0, 8]. With no mask or dropout, what is the attention output?

Answer: C. [1, 6]

Softmax([0, ln 3]) = [1/(1+3), 3/(1+3)] = [0.25, 0.75]. The output is 0.25[4,0] + 0.75[0,8] = [1,6]. Scores must be normalized before they are used as weights.

Q18Multiple Choice7 · slides 32, 36
A query–key dot product is 16 and dk = 64. What score is passed to softmax before any masking?

Answer: A. 2

The scale is √64 = 8, so the scaled score is 16/8 = 2. Dividing by dk itself would incorrectly give 0.25.

Q19Multiple Choice7 · slide 36
A single self-attention head receives 5 tokens. Q and K each have shape 5 × 4, and V has shape 5 × 6. What are the shapes of the attention-weight matrix and the head output, respectively?

Answer: B. 5 × 5 and 5 × 6

QKT multiplies (5×4)(4×5), producing 5×5 scores. Multiplying the normalized 5×5 weights by the 5×6 value matrix produces a 5×6 output. Query/key width and value width need not be equal.

Q20Multiple Choice7 · slides 36, 53
In one cross-attention head, there are 4 target query positions and 7 source key/value positions. The value dimension is 8. What are the attention-weight and output shapes?

Answer: D. 4 × 7 and 4 × 8

There is one row for each of the 4 target queries and one column for each of the 7 source keys. Thus the weights have shape 4×7; multiplying by V of shape 7×8 produces 4×8.

Q21Multiple Choice7 · slides 40, 61
A multi-head attention layer uses dmodel = 512 and 8 heads, with dk = dv = dmodel/8. What are the value width per head and the concatenated output width?

Answer: C. 64 and 512

Each head has value width 512/8 = 64. Concatenating 8 head outputs gives 8×64 = 512 features per token, before applying WO.

Q22Multiple Choice7 · slides 50–52
For a length-5 decoder input, a causal mask allows each query to attend to itself and earlier positions. At input position 3 (one-based indexing), which key positions are allowed?

Answer: A. 1, 2 and 3

The standard causal mask permits key positions j ≤ i. At i = 3, positions 1, 2 and 3 are allowed. With right-shifted training inputs, attending to the current input position still does not reveal the target token being predicted.

Q23Multiple Choice7 · slides 63–65, 70
For fixed head count and dimensions, sequence length increases from 512 to 2048. By what factor does the number of entries in a full n × n self-attention score matrix increase?

Answer: D. 16×

The sequence becomes 4 times longer, so the pairwise score matrix has 4² = 16 times as many entries. This is a statement about the dense pairwise matrix, not a guarantee that total runtime increases by exactly 16 times.

Q24Multiple Choice7 · slides 44, 61
An FFN maps 512 features to 2048 and then back to 512. Ignoring biases, how many weight parameters are in these two linear transformations together?

Answer: B. 2,097,152

The first matrix has 512×2048 = 1,048,576 weights, and the second has 2048×512 = 1,048,576. The total is 2,097,152. These matrices are shared across token positions, so sequence length does not multiply the parameter count.

Part 3 · Multiple Answer

Select all correct options. A question is correct only when the selected set matches exactly.

Q25Multiple Answer7 · slides 31–36, 50–51
Which statements about a standard scaled dot-product attention head are correct? Assume at least one unmasked key per query and no attention dropout. Select all that apply.

Answer: A. Its query, key and value projection matrices are learned parameters.
B. The weights over allowed keys are nonnegative and sum to 1 for each query.
D. A mask can prevent selected key positions from contributing to a query’s output.

A, B and D are correct. The projections are learned, and row-wise softmax produces a distribution over allowed keys. C is false: Q and K generally use different projections, and row-wise normalization also does not enforce symmetry.

Q26Multiple Answer7 · slides 46–49
Which components occur in the original encoder–decoder Transformer described in the lecture? Select all that apply.

Answer: A. Encoder self-attention and position-wise feedforward sub-layers.
B. Decoder causal self-attention and encoder–decoder cross-attention.

A and B are correct. Both encoder and decoder use residual connections and layer normalization, so C is false. Different heads have their own projections, and different layers need not share parameters, so D is also false.

Q27Multiple Answer7 · slides 42–43
Which statements about the positional encodings discussed in the lecture are correct? Select all that apply.

Answer: A. Sinusoidal positional encodings can be fixed rather than learned.
C. Learned positional embeddings are another way to represent positions.
D. When a position vector is added to a token embedding, their dimensions must match.

A, C and D are correct. The slides describe both fixed sine/cosine encodings and learned position embeddings. Softmax normalizes attention scores; that operation alone does not supply absolute position information.

Q28Multiple Answer7 · slide 74
Consider ordinary autoregressive inference in a causal Transformer decoder, with fixed model weights and a full KV cache. Which statements are correct? Select all that apply.

Answer: A. Previously computed key and value vectors can be reused at later generation steps.
B. The new token’s query attends to the available keys, including cached keys from earlier tokens.
D. Appending a token does not change earlier tokens’ causal states, which enables reuse of their keys and values.

A, B and D are correct. Earlier positions cannot attend to newly appended future positions, so their cached keys and values remain valid. The next generated token still depends on the tokens already generated; caching does not remove this sequential dependence.

Q29Multiple Answer7 · slides 69–73, 81–82
Which pairings of an efficiency method and its main idea are correct? Select all that apply.

Answer: A. Longformer / Big Bird: use sparse attention patterns.
B. Linformer: use a low-rank approach by projecting the sequence-length dimension of keys and values.
C. Dense FlashAttention: reorganize computation to reduce memory transfers while computing exact attention.

A, B and C match the lecture. Sparse and low-rank methods change the attention computation or its connectivity. Dense FlashAttention improves memory access but still computes dense pairwise attention; it does not make the number of token pairs linear.

Q30Multiple Answer7 · slides 49–51, 57
Which statements about standard encoder–decoder Transformer training for translation are correct? Select all that apply.

Answer: A. Training minimizes a token-level cross-entropy loss on the target translation.
D. During teacher-forced training, shifted target inputs and causal masking allow parallel computation across target positions.

A and D are correct. Standard training propagates gradients through both the encoder and decoder. The loss compares predicted distributions with gold target tokens. At inference, the gold translation is unavailable; the decoder uses the generated prefix instead.

Part 4 · True / False

Decide whether each statement is true or false.

Q31True / False7 · slides 14–19
A static word embedding and a contextual embedding must both assign exactly the same representation to every occurrence of the same word.

Answer: False

False. A static lookup uses one vector per vocabulary entry. A contextual embedding can change with the surrounding tokens, allowing different uses of the same word to have different representations.

Q32True / False7 · slides 32, 36
For a query–key dot product to be defined, the query and key dimensions must match, but the value dimension may be different.

Answer: True

True. q·k requires equal query and key widths. The resulting scalar weights can combine value vectors of any common value width dv; that width determines the head output size.

Q33True / False7 · slide 42
For unrestricted self-attention with shared token-wise projections, no positional information and no dropout, permuting the input token order permutes the output token order in the same way.

Answer: True

True. This is permutation equivariance. Reordering inputs reorders queries, keys and values consistently, so the output follows the same permutation. It does not mean the ordered output matrix stays unchanged.

Q34True / False7 · slides 32–36, 44
Self-attention is a linear function of its input embeddings simply because its output is a weighted sum of value vectors.

Answer: False

False. The weights themselves depend on the inputs through query–key scores and softmax, so the full mapping is generally nonlinear. For fixed weights, the combination is linear in V. The FFN adds a separate nonlinear feature transformation.

Q35True / False7 · slides 49–53
In standard offline machine translation, decoder cross-attention must causally mask later source positions to prevent access to future target tokens.

Answer: False

False. The complete source sentence is available in offline translation, so decoder cross-attention may use all non-padding source positions. The causal restriction concerns target-side self-attention. Streaming translation can impose additional source-access constraints.

Q36True / False7 · slides 50–51
With finite scores at allowed positions, at least one allowed key per row, and an additive −∞ mask at forbidden positions before softmax, forbidden positions receive zero attention probability.

Answer: True

True. exp(−∞) = 0, while the allowed scores provide a positive normalization denominator. Masking before softmax excludes forbidden positions and normalizes over the allowed ones.

Q37True / False7 · slide 48
Standard Transformer layer normalization normalizes across the feature dimensions of each token representation, rather than estimating its mean and variance across the batch.

Answer: True

True. For each token vector, LayerNorm uses statistics across its features and then applies learned scale and shift parameters. This differs from normalization based on batch statistics.

Q38True / False7 · slides 69–73
Dense FlashAttention is approximate because it discards small attention weights.

Answer: False

False. Dense FlashAttention computes exact attention, up to ordinary floating-point rounding, using a different computation and memory-access schedule. Discarding selected connections belongs to sparse or approximate attention approaches.

Q39True / False7 · slide 74
For a standard full KV cache with fixed layers, heads, dimensions and precision, caching more generated tokens increases the cache memory in proportion to the number of cached tokens.

Answer: True

True. Each new token adds a fixed amount of key and value data per layer. For a batch of one with ordinary multi-head attention, this is proportional to L×h×n×(dk+dv) stored elements. The speed benefit comes with growing cache storage.

Q40True / False7 · slides 45, 63
Because Transformers are easier to parallelize than LSTMs, a Transformer is guaranteed to run faster and use fewer parameters for every task and sequence length.

Answer: False

False. Parallelism is an architectural advantage, but runtime also depends on sequence length, model size, hardware, kernels and whether the model is training or generating. Parameter count depends on the chosen architecture; dense self-attention also has quadratic pairwise cost.
