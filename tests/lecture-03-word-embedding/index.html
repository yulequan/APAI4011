Part 1 · Multiple Choice

Q1Multiple ChoicePDF p.10

Replacing word-identity (one-hot) features with word vectors mainly helps because:

  • A. The model no longer needs labeled training data.
  • B. The model can generalize to similar but unseen words at test time.
  • C. The model's training accuracy is guaranteed to be 100%.
  • D. The number of features becomes larger and therefore more expressive.

Answer: B. The model can generalize to similar but unseen words at test time.

With one-hot features a word must be seen in training before it can get a useful weight. With word vectors, an unseen word that is close in embedding space (e.g., “motel” near “hotel”) can still be handled.

Q2Multiple ChoicePDF p.18

The lecture argues that sparse count vectors cannot capture high-order co-occurrence. Which example illustrates this problem?

  • A. High-frequency words dominate the raw counts.
  • B. Count vectors contain negative values that are hard to interpret.
  • C. Count vectors cannot be L2-normalized.
  • D. w₁ co-occurs with “car” and w₂ co-occurs with “automobile”; they should be similar, but “car” and “automobile” are distinct dimensions.

Answer: D. w₁ co-occurs with “car” and w₂ co-occurs with “automobile”; they should be similar, but “car” and “automobile” are distinct dimensions.

Because “car” and “automobile” occupy two separate dimensions, w₁ and w₂ look unrelated even though they mean similar things. Dense vectors let such indirect (high-order) evidence be shared.

Q3Multiple ChoicePDF p.19–21

Which of the following is a count-based approach for obtaining dense word vectors?

  • A. Applying SVD to the word–word co-occurrence matrix and keeping only the top k singular values (as in LSA).
  • B. Training a classifier to tell real context words from randomly sampled noise words.
  • C. Backpropagating through a softmax over the whole vocabulary.
  • D. Summing the character n-gram embeddings of each word.

Answer: A. Applying SVD to the word–word co-occurrence matrix and keeping only the top k singular values (as in LSA).

Sparse word–context count matrices (e.g., PPMI) decomposed with SVD are the count-based route, an idea dating back to Latent Semantic Analysis (Deerwester et al., 1990). The other options are prediction-based.

Q4Multiple ChoicePDF p.20–21

Which group lists only prediction-based word embedding methods?

  • A. SVD, LSA, PPMI
  • B. TF-IDF, Naive Bayes, logistic regression
  • C. word2vec, GloVe, FastText
  • D. Skip-gram, SVD, GloVe

Answer: C. word2vec, GloVe, FastText

word2vec (Mikolov et al., 2013), GloVe (Pennington et al., 2014) and FastText (Bojanowski et al., 2017) all learn vectors by formulating a prediction problem on text. SVD/LSA/PPMI belong to the count-based family.

Q5Multiple ChoicePDF p.31, 33

In skip-gram with window parameter m, the context used to predict from the center word w_t consists of:

  • A. only the m words to the left of w_t
  • B. every word in the same sentence
  • C. the 2m words around w_t, including w_t itself
  • D. the 2m words inside the window (m to the left and m to the right), excluding w_t itself

Answer: D. the 2m words inside the window (m to the left and m to the right), excluding w_t itself

The context is a fixed window of size 2m. In the objective the index runs over −m ≤ j ≤ m with j ≠ 0, so the center word is never predicted from itself.

Q6Multiple ChoicePDF p.39

Which vectors are typically used as the final word embeddings for downstream use?

  • A. Only the context vectors v_w.
  • B. In the word2vec paper the center vectors u_w are used; the GloVe paper (Pennington et al., 2014) proposed using u_w + v_w.
  • C. Always u_w + v_w, because the sum is theoretically optimal.
  • D. Neither — the parameters are discarded once training finishes.

Answer: B. In the word2vec paper the center vectors u_w are used; the GloVe paper (Pennington et al., 2014) proposed using u_w + v_w.

Which set to take is an empirical question. The original word2vec paper uses the input (center) vectors u_w, which is the most common choice; GloVe proposed u_w + v_w, and Levy et al. (2015) gave an interpretation of this.

Q7Multiple ChoicePDF p.35–36

Which statement about optimizing the skip-gram objective is correct?

  • A. The objective is convex, so SGD always reaches the global optimum.
  • B. The optimum has a closed-form solution, so no gradient computation is needed.
  • C. Because u and v are learned jointly, the objective is non-convex; it is still optimized with stochastic gradient descent.
  • D. SGD cannot be used because the softmax is not differentiable.

Answer: C. Because u and v are learned jointly, the objective is non-convex; it is still optimized with stochastic gradient descent.

If u_x were fixed, the model would reduce to multinomial logistic regression (convex). Since both u and v are learned together, the joint training objective is non-convex and it is hard to find a global minimum; in practice we still run SGD: θ ← θ − η∇J(θ).

Q8Multiple ChoicePDF p.46–47

For the per-pair loss y = −log P(c | x), the gradient with respect to a context vector v_k is:

  • A. (P(k | x) − 1)·u_x if k = c, and P(k | x)·u_x if k ≠ c
  • B. P(k | x)·u_x for every k
  • C. (P(k | x) − 1)·u_x for every k
  • D. zero for every k ≠ c

Answer: A. (P(k | x) − 1)·u_x if k = c, and P(k | x)·u_x if k ≠ c

Using y = −u_x·v_c + log Σ_k exp(u_x·v_k), the derivative is −u_x for the true word and P(k | x)·u_x for the others, i.e., −u_x + P(k | x)·u_x = (P(k | x) − 1)u_x when k = c.

Q9Multiple ChoicePDF p.52, 54

In skip-gram with negative sampling (SGNS), the probabilities are modeled as:

  • A. a softmax over the entire vocabulary
  • B. the cosine similarity between u_x and v_c
  • C. a uniform distribution over the vocabulary
  • D. P(y = 1 | x, c) = σ(u_x·v_c) and P(y = 0 | x, c′) = σ(−u_x·v_c′), i.e., binary logistic regression on positive and negative pairs

Answer: D. P(y = 1 | x, c) = σ(u_x·v_c) and P(y = 0 | x, c′) = σ(−u_x·v_c′), i.e., binary logistic regression on positive and negative pairs

SGNS converts the |V|-way classification into a binary classification task: distinguish observed (center, context) pairs from noise pairs. This is the familiar binary logistic regression, but u and v are optimized together.

Q10Multiple ChoicePDF p.51–52

In practice, how many negative examples does SGNS sample, and how are they drawn?

  • A. K = 1000 negatives, drawn uniformly at random
  • B. K = 5–20 negatives, drawn from P(w) ∝ count(w)⁰·⁷⁵
  • C. K = |V| negatives, which is why it is called “negative sampling”
  • D. K = 2m negatives, drawn according to word length

Answer: B. K = 5–20 negatives, drawn from P(w) ∝ count(w)⁰·⁷⁵

Only a small number of negatives (typically 5–20) is needed. Sampling with α = 0.75 gives rare words slightly higher probability than the plain unigram distribution and works best in practice.

Q11Multiple ChoicePDF p.58

What is the key idea of GloVe?

  • A. Sample a small number of negative words for every observed pair.
  • B. Break each word into character n-grams before computing the score.
  • C. Approximate u_i·v_j directly from global co-occurrence counts X_i_j, using a weighting function that caps the importance of very frequent pairs.
  • D. Apply SVD to the PPMI matrix.

Answer: C. Approximate u_i·v_j directly from global co-occurrence counts X_i_j, using a weighting function that caps the importance of very frequent pairs.

GloVe uses the global co-occurrence statistics directly and trains faster than window-based methods while scaling to very large corpora. Option D describes the count-based route, not GloVe.

Q12Multiple ChoicePDF p.31, 33

A corpus is w₁, w₂, …, w_T and skip-gram uses a window of size 2m. How many (center word, context word) training pairs does the model create at each position t?

  • A. 2m
  • B. m
  • C. 2m + 1
  • D. |V|

Answer: A. 2m

At every position the model predicts the 2m words inside the window (m on each side). With m = 2 that is 4 pairs per position — for “into”: (into, problems), (into, turning), (into, banking), (into, crises).

Q13Multiple ChoicePDF p.59

The term “static word embeddings” means that:

  • A. the vectors are not updated during training
  • B. there is one fixed vector per word in the vocabulary, regardless of its context
  • C. the training corpus cannot be extended
  • D. the vocabulary is frozen after training

Answer: B. there is one fixed vector per word in the vocabulary, regardless of its context

word2vec, GloVe and FastText are all static: the same vector is returned for a word type in every sentence. Contextualized embeddings, mentioned at the end of the lecture, are the alternative that changes with context.

Q14Multiple ChoicePDF p.66

For the word-similarity intrinsic evaluation (e.g., WordSim-353), the standard protocol is:

  • A. report perplexity on held-out text
  • B. report classification accuracy on a downstream task
  • C. report the training loss of the embedding model
  • D. compute cosine similarity for each word pair and report the Spearman rank correlation with human judgments

Answer: D. compute cosine similarity for each word pair and report the Spearman rank correlation with human judgments

WordSim-353 contains 353 word pairs with human similarity ratings; the model's cosine similarities are compared with those ratings using the Spearman rank correlation.

Q15Multiple ChoicePDF p.68

“man : woman ≈ king : ?” tests a ____ relation, while “walked : walking ≈ swam : ?” tests a ____ relation.

  • A. syntactic; semantic
  • B. orthographic; morphological
  • C. semantic; syntactic
  • D. semantic; orthographic

Answer: C. semantic; syntactic

Gender and country–capital analogies are semantic relations; verb-tense and adjective–adverb analogies are syntactic ones. Both are intrinsic evaluations on the analogy test set.

Q16Multiple ChoicePDF p.64

To use word embeddings for document classification in an extrinsic evaluation, a simple approach is to:

  • A. sum or average the word vectors of the document and train a logistic regression classifier on the resulting vector
  • B. concatenate the one-hot vectors of all words in the document
  • C. compute the SVD of the document–term matrix
  • D. use the softmax over the vocabulary as the classifier

Answer: A. sum or average the word vectors of the document and train a logistic regression classifier on the resulting vector

vec(x) = e(x₁) + e(x₂) + … + e(xₙ) gives a fixed-length document vector, on which a logistic regression classifier can be trained exactly as before — replacing the bag-of-words representation.

Q17Multiple ChoicePDF p.16, 25

Which statement about cosine similarity is correct?

  • A. cos(u, v) ∈ [0, 1], and it equals 1 only for identical words.
  • B. cos(u, v) ∈ [−1, 1], and it ignores the magnitudes (lengths) of the vectors.
  • C. cos(u, v) ∈ (−∞, ∞), and a larger magnitude always means a larger similarity.
  • D. cos(u, v) = 1 whenever the two vectors are orthogonal.

Answer: B. cos(u, v) ∈ [−1, 1], and it ignores the magnitudes (lengths) of the vectors.

Cosine similarity normalizes the dot product by the two norms, so it ranges from −1 to 1 and measures only the angle — which is why it is preferred over the raw dot product for word vectors.

Q18Multiple ChoicePDF p.23

Word embedding training takes as input a large text corpus, a predefined vocabulary V, and the embedding dimension d. What is the output?

  • A. A probability distribution over the documents in the corpus
  • B. A |V| × |V| co-occurrence count matrix
  • C. A function f : V → ℝᵈ that maps each word to a low-dimensional real-valued vector
  • D. One single vector that summarizes the whole corpus

Answer: C. A function f : V → ℝᵈ that maps each word to a low-dimensional real-valued vector

The learned object is a lookup from words to vectors: f : V → ℝᵈ, with d typically 50–300. The co-occurrence matrix is an ingredient of count-based methods, not the output of word2vec-style training.

Part 2 · True / False

Q1True / FalsePDF p.15, 17

A word–word co-occurrence count vector is short and dense, with one dimension per word in the context window.

  • T. True
  • F. False

Answer: False

The opposite is true: each word is represented by its row of the word–word co-occurrence matrix, so the vector has |V| dimensions (vocabulary size) and most entries are zero — long and sparse.

Q2True / FalsePDF p.19

Keeping only the top k singular values of the count matrix (SVD) is a count-based way to obtain shorter, dense vectors.

  • T. True
  • F. False

Answer: True

Approximating the full matrix with its top k (e.g., 100) singular values is exactly the LSA-style count-based recipe for dense vectors.

Q3True / FalsePDF p.35–36

The skip-gram objective is convex in the parameters, so SGD is guaranteed to find the global optimum.

  • T. True
  • F. False

Answer: False

Learning u and v jointly makes the objective non-convex. If u_x were fixed, the problem would reduce to multinomial logistic regression, but that is not the case during training, so we can only seek a good local optimum with SGD.

Q4True / FalsePDF p.37

A skip-gram model with embedding dimension d has 2d|V| parameters.

  • T. True
  • F. False

Answer: True

Every word in V keeps one center vector u_w ∈ ℝᵈ and one context vector v_w ∈ ℝᵈ, giving 2d|V| parameters in total.

Q5True / FalsePDF p.51–53

In SGNS, one update touches only u_x plus the (K + 1) context vectors of the positive and negative samples; all other context vectors stay unchanged at that step.

  • T. True
  • F. False

Answer: True

That is exactly why negative sampling is cheap: instead of updating all |V| context vectors, only the positive context vector and the K sampled negatives are updated — (K + 2) vectors in total.

Q6True / FalsePDF p.52

SGNS draws its negative words uniformly at random from the vocabulary.

  • T. True
  • F. False

Answer: False

Negatives are drawn according to P(w) ∝ count(w)⁰·⁷⁵ (a smoothed unigram distribution). The exponent 0.75 gives rare words a slightly higher probability than the plain frequency distribution, which works best in practice.

Q7True / FalsePDF p.58

GloVe approximates u_i·v_j directly from global co-occurrence counts and uses a weighting function that limits the influence of very frequent pairs.

  • T. True
  • F. False

Answer: True

The weighting function f gives more importance to common pairs but is capped, so that extremely frequent pairs do not dominate the objective. Its advantages are faster training and scalability to very large corpora.

Q8True / FalsePDF p.57

CBOW predicts the center word from the surrounding context words, which makes it a simpler task than skip-gram, and it is comparatively faster to train.

  • T. True
  • F. False

Answer: True

CBOW averages the context vectors and predicts the single center word, whereas skip-gram must make 2m separate predictions per position. CBOW is therefore faster and better for frequent words; skip-gram is slower but better for rare words and smaller corpora.

Q9True / FalsePDF p.59

FastText represents a word by summing the embeddings of its character n-grams (n = 3–6), including the word itself.

  • T. True
  • F. False

Answer: True

For “where” the n-grams are <wh, whe, her, ere, re> (3-grams), <whe, wher, here, ere> (4-grams), etc., and the word itself; the score u_x·v_c is replaced by the sum over these sub-word embeddings.

Q10True / FalsePDF p.59

With static word embeddings, the word “bank” has one single vector in all contexts.

  • T. True
  • F. False

Answer: True

“Static” means one fixed vector for every word in the vocabulary, so a river bank and a financial bank share the same vector. Contextualized embeddings are the alternative that produces a different vector per occurrence.

Q11True / FalsePDF p.63, 65

Extrinsic evaluation is fast to compute, but it is unclear whether it really helps downstream tasks.

  • T. True
  • F. False

Answer: False

This describes intrinsic evaluation. Extrinsic evaluation plugs the embeddings into a real NLP system and measures end-to-end performance: it can take a long time but it is still the most important evaluation metric.

Q12True / FalsePDF p.63, 68

Word analogy is an extrinsic evaluation method.

  • T. True
  • F. False

Answer: False

Word analogy is intrinsic: it judges the vectors on a specific intermediate subtask rather than on a real application. Extrinsic evaluation means plugging the embeddings into a downstream NLP system and measuring its performance.

Q13True / FalsePDF p.37, 40

The number of parameters in skip-gram depends on the length T of the training corpus.

  • T. True
  • F. False

Answer: False

The parameter count is 2d|V|, which depends only on the vocabulary and the embedding dimension. The corpus length T determines how many training pairs (and gradient steps) you get, not how many parameters the model has.

Q14True / FalsePDF p.59

Contextualized embeddings assign different vectors to the same word in different sentences, unlike word2vec, GloVe and FastText.

  • T. True
  • F. False

Answer: True

The lecture ends by flagging contextualized word embeddings as the next step: instead of one fixed vector per word type (static embeddings), the representation depends on the sentence the word appears in.
