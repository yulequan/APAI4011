Part 1 · Multiple Choice (Analysis)

Q1Multiple Choice4.2 · slide 26

Model A has perplexity 40 on a test corpus; model B has perplexity 320. Roughly how much worse is B, in bits per word?

  • A. 1 bit
  • B. 3 bits
  • C. 8 bits
  • D. 280 bits

Answer: B. 3 bits

Bits per word = log2 of perplexity. log2 320 − log2 40 = log2(320/40) = log2 8 = 3. (Model A needs about 5.3 bits/word; model B about 8.3.) Perplexity ratios become bit differences by taking log2.

Q2Multiple Choice4.2 · slides 26–28

A bigram model achieves perplexity 100 on a test corpus. Which interpretation is most accurate?

  • A. On average, the model is as uncertain as if it were choosing uniformly among about 100 words at each step.
  • B. The model makes a prediction error on about 1% of the words.
  • C. The model would need exactly 100 bits to encode each word.
  • D. The model assigns probability 100 to the most likely word.

Answer: A. On average, the model is as uncertain as if it were choosing uniformly among about 100 words at each step.

Perplexity is the (geometric-mean) inverse probability of the corpus; ppl = 100 behaves like a “weighted average branching factor” of 100 — similar to the uniform model whose perplexity equals |V|. It says nothing about a 1% error rate, bits per word is log2 100 ≈ 6.6 (not 100), and probabilities are at most 1.

Q3Multiple Choice4.2 · slides 34, 38

A trigram never seen in training (“saw a sequoia”) has MLE probability 0. Suppose P(sequoia | a) = 0.10 for the bigram and P(sequoia) = 0.01 for the unigram, with interpolation weights λ1 = 0.6, λ2 = 0.3, λ3 = 0.1. What does the interpolated estimate give?

  • A. 0 — the trigram has zero count
  • B. 0.100
  • C. 0.110
  • D. 0.031

Answer: D. 0.031

0.6 × 0 + 0.3 × 0.10 + 0.1 × 0.01 = 0.03 + 0.001 = 0.031. This is the whole point of interpolation: even when the highest-order estimate is zero, lower-order evidence keeps the probability non-zero, so no test sentence ends up with probability zero.

Q4Multiple Choice4.2 · slides 34, 38

You apply Laplace smoothing to a trigram model and evaluate on the same test corpus: α = 1 gives perplexity 240, α = 0.01 gives 180, and α = 0.0001 gives 195. What is the best interpretation?

  • A. The results are impossible — smoothing should only improve perplexity.
  • B. The smallest α is always best, because it distorts the observed counts least.
  • C. There is a trade-off between modeling unseen n-grams and preserving reliable estimates from observed counts; α should be tuned on a development set.
  • D. The model should drop smoothing entirely and report the infinite perplexity.

Answer: C. There is a trade-off between modeling unseen n-grams and preserving reliable estimates from observed counts; α should be tuned on a development set.

Smoothing moves probability mass from observed to unobserved events. Too little α handles unseen n-grams poorly; too much α deforms the good estimates (as α → ∞ the model approaches uniform, with perplexity ≈ |V|). The hyperparameter is tuned on held-out development data — never on the test set — exactly like the interpolation weights λ.

Q5Multiple Choice4.2 · slides 25, 31

A report claims “model X has perplexity 55 and model Y has perplexity 48, so Y is better.” Under which condition is this comparison NOT meaningful?

  • A. X and Y are evaluated on different test corpora (or use different vocabularies).
  • B. X and Y are the same architecture with different n-gram orders.
  • C. X and Y are evaluated on the same test corpus with the same vocabulary.
  • D. One of X and Y is smoothed.

Answer: A. X and Y are evaluated on different test corpora (or use different vocabularies).

Perplexity depends on both the model and the evaluation data: vocabulary, tokenization and domain all change the number. Comparing perplexities across different test sets or vocabularies is not meaningful — the scores must come from the same corpus and the same vocabulary. Options B–D are perfectly meaningful comparisons.

Q6Multiple Choice4.2 · slide 48

The feedforward neural LM concatenates the m word embeddings into x ∈ ℝmd rather than averaging them. What is the main reason?

  • A. Concatenation is much cheaper to compute than averaging.
  • B. Averaging would make the gradients vanish.
  • C. Averaging prevents the use of a softmax output layer.
  • D. Averaging would discard word-order information: “the cat sat on” and “on sat cat the” would give the same representation.

Answer: D. Averaging would discard word-order information: “the cat sat on” and “on sat cat the” would give the same representation.

Averaging is commutative, so any permutation of the same window would produce an identical input vector. Concatenation keeps each position separate (each position also maps to its own slice of W) — the lecture flags exactly this “why concat instead of taking the average?” point.

Q7Multiple Choice4.2 · slides 47–49

A feedforward neural LM has window m = 5, embedding size d = 100, hidden size h = 200, vocabulary |V| = 10,000. Ignoring biases, how many parameters do the embedding matrix E, the input-to-hidden matrix W and the output matrix U have in total?

  • A. 3.1 million
  • B. 1.1 million
  • C. 2.1 million
  • D. 3.0 million

Answer: A. 3.1 million

E: |V| × d = 10,000 × 100 = 1,000,000. W: h × 5d = 200 × 500 = 100,000. U: |V| × h = 10,000 × 200 = 2,000,000. Total = 3.1M. Note how the output matrix U dominates — it grows with |V|, while W grows only with the window.

Q8Multiple Choice5.1 · slide 59

A simple RNNLM has |V| = 10,000 and d = h = 200. With weight tying (E and Wo merged), and ignoring biases, roughly how many parameters does the model have?

  • A. 2.04 million
  • B. 4.08 million
  • C. 2.08 million
  • D. 4.00 million

Answer: C. 2.08 million

E: 10,000 × 200 = 2.00M; W: 200 × 200 = 40k; U: 200 × 200 = 40k (because d = h). Wo is merged with E thanks to tying, so it adds nothing: 2.08M in total. Without tying, a separate Wo ∈ ℝ|V|×h would add another 2.00M, giving 4.08M — the saving is exactly the point of weight tying.

Q9Multiple Choice5.1 · slides 18, 25

Suppose that for a simple RNN, each time step’s Jacobian factor multiplies the gradient by about 0.5 on average. Approximately what factor remains after back-propagating 10 steps?

  • A. About 0.5
  • B. About 10−3
  • C. About 10−10
  • D. About 0.1

Answer: B. About 10−3

0.510 = 1/1024 ≈ 0.001 = 10−3. After 20 steps it is about 10−6, and after 60 steps about 10−18. This exponential decay is exactly the vanishing gradient problem; with average factors above 1 the same reasoning gives exploding gradients.

Q10Multiple Choice5.1 · slide 30

A model is trained with truncated BPTT (chunk length 20). A dependency 60 steps back cannot receive gradient directly. Why might the model still capture some long-range information?

  • A. It cannot — truncation prevents modeling long-range dependencies entirely.
  • B. Gradient clipping restores the missing long-range gradients.
  • C. The hidden state is carried forward across chunks, so information can still flow through the state over time.
  • D. The loss is accumulated across chunks, so gradients implicitly connect all time steps.

Answer: C. The hidden state is carried forward across chunks, so information can still flow through the state over time.

Truncation limits only the backward pass. The forward pass never resets: the lecture’s description is “carry hidden states forward in time forever, but only back-propagate for some smaller number of steps.” Long-range information can therefore still be carried by the state, even though gradients do not reach 60 steps back.

Q11Multiple Choice5.1 · slides 19–29

Two RNNLM training runs show different symptoms. Which one is the signature of vanishing gradients, rather than exploding gradients?

  • A. The loss suddenly becomes NaN after a few thousand steps.
  • B. The loss oscillates wildly and diverges.
  • C. The model performs perfectly on the training set but poorly on the development set.
  • D. The model predicts local structure well, but keeps making agreement mistakes between words that are far apart (e.g., subject and verb).

Answer: D. The model predicts local structure well, but keeps making agreement mistakes between words that are far apart (e.g., subject and verb).

Exploding gradients produce instability — divergence and NaN losses — and are mitigated by gradient clipping. Vanishing gradients leave training stable but make it hard for the model to use information from many steps back, which shows up precisely as errors on long-range dependencies such as subject–verb agreement (the “writer of the books is/are” example). Option C is ordinary overfitting.

Q12Multiple Choice5.1 · slides 40–47

You need a part-of-speech tagger. You process complete sentences offline, and accuracy is the priority. Which design is best justified?

  • A. A unidirectional (forward-only) RNN, because bidirectionality would break the causality of tagging.
  • B. A multi-layer bidirectional RNN, since the entire input sequence is available and bidirectionality is powerful in that case.
  • C. A single-layer unidirectional RNN, because extra layers only help for text generation.
  • D. A feedforward network with a window of 5 words, because tagging is a purely local task.

Answer: B. A multi-layer bidirectional RNN, since the entire input sequence is available and bidirectionality is powerful in that case.

A tag benefits from both sides of context (e.g., “terribly” is disambiguated by the left context “the movie was” and the right context “exciting!”). Offline processing means the whole sentence is available, and the lecture’s advice is to use bidirectionality by default in that case — for sequence tagging especially. Stacking 2–4 layers is usually better than one. Options A and C rest on false premises, and D ignores long-range context.

Q13Multiple Choice5.1 · slides 7–8

A simple RNN cell computes ht = g(W ht−1 + U xt + b) with hidden size h = 200 and input size d = 100. How many parameters are in one cell (W, U and b)?

  • A. 60,200
  • B. 40,200
  • C. 40,000
  • D. 20,000

Answer: A. 60,200

W ∈ ℝh×h: 200 × 200 = 40,000. U ∈ ℝh×d: 200 × 100 = 20,000. b ∈ ℝh: 200. Total = h(h + d + 1) = 200 × 301 = 60,200. Crucially, this number is fixed — it does not depend on how long the input sequence is.

Q14Multiple Choice5.1 · slides 20, 32

For text generation with an RNNLM, you consider always picking the most likely next word (greedy) versus sampling from the distribution. Which statement is most accurate?

  • A. Greedy decoding returns the globally most probable sentence, since every step is optimal.
  • B. Sampling always produces sentences with higher total probability.
  • C. The two methods produce identical outputs with the same model.
  • D. Greedy decoding is deterministic and can fall into repetitive loops; sampling gives more varied text, at the price of sometimes taking lower-probability steps.

Answer: D. Greedy decoding is deterministic and can fall into repetitive loops; sampling gives more varied text, at the price of sometimes taking lower-probability steps.

Greedy choice is locally optimal at each step, not globally: the highest-probability whole sentence may require an initially lower-probability word, and always taking the argmax readily degenerates into repeated loops. Sampling draws from the distribution — the lecture’s generation recipe (“sampled output is next step’s input”) — which increases variety but does not guarantee high-probability sentences (A, B and C are all false for these reasons).

Q15Multiple Choice4.2 · slides 34, 37

Counts from a training corpus: C(the cat) = 120 and C(the cat sat) = 18. With Laplace smoothing (α = 1) and |V| = 5,000, what is the smoothed estimate of P(sat | the cat)?

  • A. 18 / 120 = 0.150
  • B. 19 / 5,120 ≈ 0.0037
  • C. 19 / 120 ≈ 0.158
  • D. 18 / 5,120 ≈ 0.0035

Answer: B. 19 / 5,120 ≈ 0.0037

The smoothed MLE is (C(the cat sat) + α) / (C(the cat) + α|V|) = (18 + 1) / (120 + 5,000) = 19 / 5,120 ≈ 0.0037. Adding α to every count changes both the numerator and the denominator — the denominator gains one α for each of the |V| possible continuations, which is why the probability shrinks so much compared with the raw ratio.

Q16Multiple Choice4.2 · slides 24–25

Two language models: model A has clearly better (lower) perplexity, but model B gives higher accuracy when plugged into your downstream question-answering system. What should you conclude?

  • A. There must be a bug — lower perplexity always means better downstream performance.
  • B. Perplexity is useless and should be abandoned as a metric.
  • C. Intrinsic scores do not always translate into downstream gains; if the task metric is what matters, prefer B — the extrinsic-evaluation perspective.
  • D. The two models are equally good, since the metrics disagree.

Answer: C. Intrinsic scores do not always translate into downstream gains; if the task metric is what matters, prefer B — the extrinsic-evaluation perspective.

Extrinsic evaluation (train LM → apply to task → observe accuracy) measures what we actually care about, at the cost of being expensive; intrinsic metrics like perplexity are convenient proxies that do not guarantee better task accuracy. “Always” (A) and “useless” (B) are both too strong, and D ignores the objective you are optimizing.

Part 2 · Multiple Answers (select all that apply)

Q1Multiple Answers4.2 · slides 25, 32, 38

Which of the following reduce a trigram model’s test-set perplexity without violating the evaluation protocol? Select all that apply.

  • A. Tuning the interpolation weights λ directly on the test set.
  • B. Applying smoothing (e.g., interpolation) to the model’s estimates.
  • C. Tuning the interpolation weights λ on a held-out development set.
  • D. Collecting additional training data from the same domain.

Answer: B, C and D.

Smoothing fixes zero probabilities, more in-domain data improves the estimates, and hyperparameters (λ, α) belong on the development set. Tuning anything on the test set is not acceptable — the test corpus must stay unseen, exactly as with “training on any part of test set not acceptable”.

Q2Multiple Answers5.1 · slides 10, 16, 59

Per time step, an RNNLM costs O(h × (d + h + |V|)). Which changes reduce that per-step cost? Select all that apply.

  • A. Decreasing the hidden size h.
  • B. Increasing the vocabulary size |V|.
  • C. Decreasing the embedding size d.
  • D. Applying weight tying.

Answer: A and C.

Smaller h shrinks every term, including the dominant h × |V| output cost; smaller d shrinks the U xt term. Weight tying reduces the number of parameters but not the computation — the |V|-sized output matrix and softmax still run at every step. Increasing |V| makes the dominant term worse.

Q3Multiple Answers5.1 · slides 28–29

Which statements about gradient clipping are correct? Select all that apply.

  • A. If the gradient’s norm exceeds a threshold, it is scaled down before the SGD update.
  • B. It also fixes vanishing gradients by amplifying gradients that are too small.
  • C. When scaling by the norm, the update direction is preserved — only the magnitude changes.
  • D. It helps prevent the instability (divergence, NaN losses) caused by exploding gradients.

Answer: A, C and D.

Clipping caps large gradients: g ← g × (threshold / ‖g‖), which keeps the direction and shortens the step, stabilizing training (A, C, D). It never amplifies small gradients, so it does not address vanishing gradients — those are a harder problem, motivating gated variants like LSTMs.

Q4Multiple Answers5.1 · slides 36–47

Which task–architecture pairings are sensible? Select all that apply.

  • A. Bidirectional RNN as the language model for autoregressive text generation.
  • B. Left-to-right (unidirectional) RNN for on-the-fly next-word prediction as a user types.
  • C. Multi-layer bidirectional RNN for sentence-level sentiment classification.
  • D. Single-layer unidirectional RNN for offline part-of-speech tagging, chosen because it gives the best accuracy.

Answer: B and C.

B: prediction must be causal — no future tokens exist yet, so left-to-right fits. C: the whole sentence is available, and pooling or concatenating the two directions is common practice (the key idea behind BERT). A: generation cannot see the future, so bidirectionality is invalid there. D: offline tagging can see the whole sentence, so a bidirectional tagger is available and typically more accurate — the stated rationale fails.

Part 3 · True / False (Reasoning)

Q1True / False4.2 · slide 26

If a model assigns the same probability p to every gold word of a corpus, its perplexity is 1/p, regardless of the corpus length.

  • T. True
  • F. False

Answer: True

ppl = P(corpus)−1/n = (pn)−1/n = 1/p — the length n cancels out. This is why perplexity is a per-word measure and why the uniform model (p = 1/|V|) has perplexity exactly |V|.

Q2True / False4.2 · slides 25–26

If model A has lower perplexity than model B on the same test corpus, then A assigns a higher probability to every individual sentence of that corpus.

  • T. True
  • F. False

Answer: False

Perplexity is an aggregate (geometric-mean) measure over the whole corpus. A is better on average, but on any particular sentence B may assign the higher probability — the two models can trade off, and a lower average does not imply pointwise dominance.

Q3True / False4.2 · slide 31

A trigram model with no smoothing can have infinite (undefined) perplexity on a test corpus even if the vast majority of its trigram estimates are perfectly reasonable.

  • T. True
  • F. False

Answer: True

Perplexity is built from P(corpus) = product over positions; a single zero-probability n-gram makes the whole product zero, hence undefined (infinite) perplexity — the sparsity problem that motivates smoothing. One bad estimate is enough.

Q4True / False4.2 · slides 48–50

In a feedforward neural LM, increasing the window from m = 5 to m = 10 (with d, h and |V| fixed) has no effect on the number of parameters.

  • T. True
  • F. False

Answer: False

W ∈ ℝh × m·d grows in proportion to m, so the parameter count increases (roughly doubling here). This is precisely the limitation that “W scales linearly with the context size m” — and one reason recurrent architectures are attractive.

Q5True / False5.1 · slides 28–29

Gradient clipping can also alleviate the vanishing gradient problem, because it rescales gradients that are too small.

  • T. True
  • F. False

Answer: False

Clipping only shrinks gradients whose norm is too large; it never amplifies small ones. Vanishing gradients are the harder problem, and the lecture points to advanced RNN variants (LSTMs, GRUs) instead — clipping is the standard remedy for exploding gradients (which produces the largest gradient norms).

Q6True / False5.1 · slides 7–8, 13

Because an RNN reuses the same weights at every step, both its parameter count and the compute needed for one forward pass are independent of the sequence length.

  • T. True
  • F. False

Answer: False

The first half is true — the parameter count is independent of length, which is a genuine advantage of RNNs (“model size doesn’t increase for longer input context”). But compute is not: a forward pass touches n time steps, costing O(n × h × (d + h + |V|)), growing linearly with the input length.

Q7True / False5.1 · slide 59

Weight tying (merging E and Wo when d = h) reduces the number of parameters but does not remove the |V|-sized softmax computation at each step.

  • T. True
  • F. False

Answer: True

Tying shares the values of the matrices (saving |V| × h parameters), but the model still computes z = Wo ht over all |V| words and normalizes with a softmax at every step. Parameter savings and compute savings are different things.

Q8True / False5.1 · slide 30

In truncated BPTT, the hidden state arriving at a chunk boundary is treated as a constant during the backward pass — no gradient flows across the boundary.

  • T. True
  • F. False

Answer: True

Truncated BPTT runs forward and backward per chunk: the carried-in state acts as a fixed initial state for that chunk’s backward pass, and only within-chunk steps receive gradient. Information still flows forward through the state across chunks — it is the backward gradient connection that is cut.

Q9True / False4.2 · slide 26

Perplexity 1 on a test corpus means the model assigned probability 1 to every gold word of that corpus.

  • T. True
  • F. False

Answer: True

ppl = P(corpus)−1/n = 1 requires P(corpus) = 1, i.e., every factor equals 1 (probabilities never exceed 1). It is the unattainable lower bound — perfect certainty at every step — which no real LM on natural text reaches.

Q10True / False4.2 · slides 32–34

Any smoothing method, with any hyperparameter setting, will lower perplexity relative to the unsmoothed maximum-likelihood model.

  • T. True
  • F. False

Answer: False

Over-smoothing moves too much mass to unseen events and damages reliable estimates: as α → ∞ the model drifts toward uniform and perplexity approaches |V|. Even moderate smoothing can hurt a test set that contains no unseen events. Smoothing trades bias for coverage, which is exactly why α and λ must be tuned on development data.
